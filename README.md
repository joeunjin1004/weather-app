# ☀️ WeatherCast - 실시간 날씨 조회 웹 애플리케이션

별도의 **회원가입이나 API Key 발급 없이 즉시 무료로 사용**할 수 있는 [Open-Meteo](https://open-meteo.com) 공개 기상 API를 연동하여 제작된 모던한 실시간 날씨 웹앱입니다.

---

## 🌟 주요 기능 및 특징

1. **무료 & No API Key**:
   - 상업적/비상업적 용도로 API Key 없이 즉시 호출 가능한 **Open-Meteo API**를 사용합니다.
2. **실시간 기상 정보 & 대기질(미세먼지)**:
   - 현재 기온, 체감 온도, 습도, 풍속, 강수량 실시간 표시
   - **미세먼지(PM10) & 초미세먼지(PM2.5)** 실시간 농도(µg/m³) 및 등급(좋음/보통/나쁨/매우나쁨) 프로그레스 바 표시 (무료 Air Quality API 연동)
   - 주/야간 및 날씨 상태(맑음, 흐림, 비, 눈, 뇌우 등)에 따른 동적 움직이는 배경 테마 및 아이콘 전환
3. **국가/도시별 실시간 디지털 현지 시계**:
   - 검색한 도시의 타임존을 자동 계산하여 **초 단위로 째깍째깍 흐르는 현지 시각**과 날짜를 실시간 표기
4. **해외 국가 검색 시 국제선 항공편 결항 & 운항 모니터링**:
   - 한국이 아닌 해외 국가/도시를 검색했을 때 자동으로 항공 운항 모니터링 카드가 활성화됩니다.
   - 현지 관문 공항(예: 도쿄 하네다/나리타, 뉴욕 JFK, 런던 히드로, 파리 샤를드골 등)의 악천후(폭설, 뇌우, 태풍급 강풍, 짙은 안개)에 따른 **실시간 기상 결항 위험도(%) 및 결항 주의보** 안내
   - 실시간 공항 출도착/결항 조회(Flightradar24) 원클릭 연동
5. **전 세계 & 국내 도시 검색**:
   - 한글/영문 도시명 검색 지원 (서울, 부산, 제주, 도쿄, 뉴욕, 파리 등)
   - 실시간 자동완성 추천 드롭다운
6. **위치 아이콘 원클릭 구글 맵(Google Maps) 연동**:
   - 도시명 옆의 **위치 핀 아이콘**을 클릭하면, 현재 날씨를 조회한 정확한 위도·경도 좌표의 구글 지도 페이지가 새 탭으로 즉시 열립니다.
7. **GPS 기반 내 위치 날씨**:
   - 브라우저의 위치 정보(Geolocation)를 활용해 원클릭으로 사용자의 현재 위치 날씨를 자동 조회
8. **24시간 시간별 예보 & 인터랙티브 7일 주간 일기 예보**:
   - 향후 24시간 동안의 기온 및 강수 확률 가로 스크롤
   - **주간 예보 날씨 클릭 시 배경 전환**: 주간 예보 목록에서 특정 날짜를 클릭하면, **해당 날짜의 날씨 상태(맑음, 비, 구름, 눈 등)에 맞춰 전체 뒷배경과 캔버스 애니메이션이 즉시 전환**됩니다.
9. **반응형 글래스모피즘(Glassmorphism) UI**:
   - 모바일, 태블릿, PC 어디서나 쾌적하게 볼 수 있는 감성적이고 깔끔한 디자인

## 🚀 실행 방법

### 방법 1: 브라우저에서 바로 열기
1. 폴더 내의 [`index.html`](file:///d:/조은진/02_바이브코딩/weather-app/index.html) 파일을 더블 클릭하여 크롬, 엣지, 웨일 등의 브라우저로 엽니다.
2. 별도의 웹 서버 설치 없이도 바로 동작합니다!

### 방법 2: 로컬 웹 서버 실행 (권장)
VS Code의 `Live Server` 확장을 사용하거나, 터미널에서 아래 명령어 중 하나를 실행하여 로컬 서버를 띄울 수 있습니다:

```bash
# Python이 설치되어 있는 경우
python -m http.server 8080

# 또는 npx serve를 사용할 경우
npx serve .
```
브라우저에서 `http://localhost:8080`으로 접속하시면 됩니다.
